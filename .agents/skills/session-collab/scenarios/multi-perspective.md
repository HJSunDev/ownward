# 剧本·多角度分析（2-3 角色，星型）

依据 [权威文档 §5.1](../../../docs/workbench/cross-session-collaboration.md)。

**拓扑**：星型协调+共享产物面——扩展角色只与发起人通信；线程文件各角色可读，但盲起草期间不读他人草案。不做网状。

**角色与镜头**：扩展角色各分配不同镜头（正确性/风险、简洁/可维护、体验/运维、安全/隐私、性能/成本），不得重复。默认 2 角色；启用第三角色必须先过**价值门**（request.md 写出第三镜头的独立价值与成功标准）。

| 相位 | 动作与约束 | 产物 |
| --- | --- | --- |
| request | 发起人写问题、约束、成功标准、材料、不在范围、角色与镜头、价值门 | `request.md`（expectation: draft） |
| blind-draft | 全体（含发起人）独立成稿；己方落盘前不读他人草案；草案一次写定（exchange 前不得改，时间戳可审计）；含方案、依据、风险、反对自己的最强理由、自评预期独特价值 | `drafts/<role>.md` |
| cross-critique | 全部草案齐后各读他人草案，写每份的最强处/最弱处/可合并处；禁止只附和 | `critiques/<role>.md` |
| debate | 星型：各角色只与发起人辩论，每角色每轮一次；两轮为限（一轮=各角色各回应一次） | 辩论消息 |
| converge | 发起人**唯一合成** final：delta、unique_contributions 审计、dissent；各角色标 agree\|residual-dissent | `final.md` |

**防拖累（1+1+1>3）**：价值门→独立性→交叉批判→单点合成→贡献审计。`unique_contributions`=各角色自报+发起人归因，差异记 dissent；只认相对发起人初始草案的**具体改动/决策**；无具体归因即 redundant，不计入、不进终版。

**僵局**：两轮未收敛→发起人书面裁决（争议点/各方立场/证据/理由/何种新证据可推翻），写入 `decision.md`；禁区：未关闭 blocker 或异议主张不满足成功标准时，不得单方关闭——呈用户"单一推荐版本+异议记录"，不出选择题。

**用户可见性**：只有发起人与用户对话；禁止把各角色原文倾倒给用户。
