# 剧本·多角度分析（2-3 角色，星型）

依据 [权威文档 §5.1](../../../../docs/workbench/cross-session-collaboration.md)；共同输入遵循 §3.12，完成判定遵循 §3.5。

**拓扑**：星型协调+共享产物面——扩展角色只与发起人通信；线程文件各角色可读，但盲起草期间不读他人草案。不做网状。

**角色与镜头**：扩展角色各分配不同镜头（正确性/风险、简洁/可维护、体验/运维、安全/隐私、性能/成本），不得重复。默认 2 角色；启用第三角色必须先过**价值门**（request.md 写出第三镜头的独立价值与成功标准）。

| 相位 | 动作与约束 | 产物 |
| --- | --- | --- |
| request | 按独立模式写需求与事实、有效约束、逐项成功标准、材料来源与筛选说明、角色与镜头、价值门；不得预装发起人猜测或推荐，允许自行补证；正文按消息模板分区 | `request.md`（expectation: draft） |
| blind-draft | 全体（含发起人）独立成稿；落盘前不读他人草案或混合任务其他分区的推荐；初稿在交叉批判前冻结，后续修订保留原稿与依据；含方案、依据、风险、反对自己的最强理由、自评预期独特价值 | `drafts/<role>.md` |
| cross-critique | 全部草案齐后各读他人草案，写每份的最强处/最弱处/可合并处；禁止只附和 | `critiques/<role>.md` |
| debate | 星型：每角色每轮一次，一次讨论最多两轮；无新信息提前停止重复辩论，转取证或验证；轮次不构成完成依据 | 辩论消息 |
| converge | 发起人唯一合成 final：delta、unique_contributions、dissent 与逐项达标证据；各角色标 agree\|residual-dissent，同意不代替证据；未达标继续处理具体缺口 | `final.md` |

**贡献审计**：各角色自报+发起人归因，差异记 dissent；认发现遗漏、排除错误方案、改进解法或独立验证的具体价值，不以发起人初稿为基准，不要求人人改动终稿。独立验证须说明对象、方法、证据与消除的不确定性，仅同意不算贡献。无增量贡献的角色标 `redundant`，不删除其有效意见、证据或异议；成果是否达标另按 §3.5 核验。

**推进与僵局**：证据足够且取舍在授权内，发起人书面裁决（争议点/各方立场/证据/理由/可推翻的新证据）并写入 `decision.md`。证据不足先补齐；未关闭 blocker 或有依据的未达标准异议不得单方宣布完成，能自行处理的继续。确需用户决定或权限/硬预算内无法推进时，报告“单一推荐+证据与异议”；等待裁决先 `waiting` 并按超时纪律处理，确实受阻如实记 `dead-letter`（含 `unmet`）。已达标即结束；每个新增动作须针对具体缺口，不重跑完整流程、不突破硬预算。

**用户可见性**：只有发起人与用户对话；禁止把各角色原文倾倒给用户。
