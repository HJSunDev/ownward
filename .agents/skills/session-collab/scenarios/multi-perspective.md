# 共同分析

适用于根因分析、方案设计等需要独立判断的开放问题。

1. 协调者提供原始需求、事实、约束和完成条件（范围约束只隔离超界事项，不预先排斥解决当前问题所需的具体解法），按[输入规则](../../../../docs/workbench/cross-session-collaboration.md#312-任务书保真中继失真防护)标明材料来源。默认两方；增加参与者须说明他要消除的具体不确定性，重大任务的冷读另按终审要求安排。
2. 各方先独立形成方案、依据、风险与成立条件及反对自身方案的最强理由，记录后再读对方结论；允许自行补充证据。交叉前的初稿保留，后续修正注明依据。
3. 交换质询，指出影响结果的实质缺口（含表面合规但解决不了核心难点）、反例或有效点，再各自重新判断：局部缺据、条件过宽或夹带超界枝节处分别补证、收紧或裁剪，只撤回被证伪或无法核实的内容，既不妥协盲从，也不死守己见，按[第一原则](../../../../docs/workbench/cross-session-collaboration.md#一目标与第一原则)据真实问题与证据择优，不把有效内容一并删空。分歧没有新证据时，转向查证或验证。
4. 协调者整合经核实的有效结论——互补要点合并吸收，互斥方案按证据择优单选（记录取舍与残余分歧），既不硬拼折中，也不退回双方都不出错的空话——由实施方完成目标要求的成果。各方的具体改进或独立核验证据随结论保留；不为证明贡献制造差异。
5. 各方按[达标判据](../../../../docs/workbench/cross-session-collaboration.md#35-状态与推进)和实际使用方式分别对照原始需求验收成果（核实核心难点已有实质解决，且未无故丢失初稿中未被证伪的有效内容），先记录依据或缺口再交换判断。有缺口继续处理，达标后结束。

争议证据充分且取舍在授权内时，由已指定的决策负责人选择方案并记录理由、异议和可推翻该选择的新证据。存在未解决的阻断缺陷或有依据的未达标异议时，不得单方宣布完成；用户保留的决定交由用户裁决。协调与分歧处理细则见[共同分析规则](../../../../docs/workbench/cross-session-collaboration.md#51-多角度分析2-3-角色星型)。
