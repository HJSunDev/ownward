# 决策日志（工作产物"决策"段模板）

依据 [权威文档 §3.11](../../../../docs/workbench/cross-session-collaboration.md)：D1 一行一条；D2 记决策点、对方输入、结论、证据链接；降级/未协作项单列。**D2 无日志=未完成协作。**

```markdown
## 决策

### D1（执行内选择，一行一条）
- <选择> — 依据：<先例/约定>（<触发场景一句话>）

### D2（路径决策）
- 决策点：<问题>
  - 选项：<A / B / ...>
  - 对方输入：<消息文件路径 + 一句话摘要>（无则"未协作，原因+追审状态"）
  - 结论：<选定项>
  - 证据：<链接/哈希>
  - 异议：<保留原文引用；无则填 "-">（禁止改写对方异议）

### 未协作 / 降级（单列）
- <决策点> — <为何未经协作（超时默认处置/反拖累降级/紧急）>｜追审：<待审 / 已追认 / 被重开>
```

填写约定：

- 落点（权威文档 §3.11）：交付类工作产物（代码/脚本/方案/测试等）写"决策"段；跨产物或文档/规则类决策写线程消息或 records；判据=该结论会被后续复核、复现或他人依赖引用→必须落盘；
- 咨询消息预写的"未回复默认处置"执行后，必须在此段登记，供对方下一自然回合追审；
- 反拖累降级（同类连续 ≥3 次 delta=0）须附书面提案证据链接；
- 结论被对方追审推翻时按 §1.6 重开，不得删改历史条目，追加"被重开"标注。
