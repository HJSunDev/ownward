# 评测观察器越权事故

状态：已纠正。旧结果保留为被动模式审计；产品忠实适配器、失败关闭、校准与三版同尺重比均已完成。

## 事故

LongMemEval-S 与 V2 盲测曾由宿主固定搜索、预选并读取证据，再要求禁用工具的 Reader 回答。观察器因此代替外部智能体承担了检索决策，违反[产品主动检索职责](../product/requirements.md#主动检索)与[架构边界](../architecture/overview.md#六信息内核与产品运行)。项目验证了被动评测流程，而非产品定义的外部智能体主动检索。

## 影响

| 证据 | 处置 | 原因 |
| --- | --- | --- |
| V0、V1 的内部不变量、固定质量与独立性能 | 继续有效 | 不依赖被动问答观察器 |
| V0 `242/500`、V1 `285/500` 及其分类差异 | 仅证明旧被动模式 | 固定预取与禁用工具直接决定证据交付 |
| V2 Stage 3—5 的独立机制、回归、制品与恢复证据 | 继续有效 | 不依赖旧盲测观察器的部分保持原结论 |
| V2 Stage 6 的 5/15/25 题候选判断与 `target_evidence_not_read` 归因 | 失效待重测 | 观察器而非外部智能体决定读取；`be8e7b9` 只保留历史审计意义 |
| 盲测题目生成、机械证明和先验质量准入 | 继续有效 | 在候选运行前成立，不依赖候选输出或旧检索流程 |

旧结果与 Git 历史不改写；权威文档不得再把受影响结果表述为产品能力、内核根因或晋升证明。

## 修复

- 产品评测冻结为 `external-agent-progressive/v1`：外部智能体直接获得 Ownward 工具并自主推进检索，宿主只执行工具与预算。
- 盲测与正式运行共用同一主动路径；工具缺失、禁用工具、宿主固定预取、未实际搜索或未读取证据均失败关闭。
- 旧固定预取代码仅保留为显式被动排序诊断，不进入产品裁决。
- 先用非盲材料校准工具闭环、预算、恢复、归因与成本，再在同一身份下最小充分重比 V0、V1、V2。

## 防复发原则

评测观察器必须先证明职责忠实，再证明执行稳定；观察器可以限制资源，不能代替被测产品外部角色作决策。任何评测结论都必须同时绑定候选、环境、观察器及其产品职责模式。

## 纠偏结果

干净校准 `4/4`，三版在同一主动检索 20 题非盲集合上均为 `20/20`；V2 在同等工具、模型、预算和环境下具有最低墙钟、检索均值、检索 P95 与数据量，故成为后续唯一候选基线。机器证据见[同尺重比结果](../../benchmarks/acceptance/suite/iteration/evaluation-correction/product-faithful-comparison.json)。未运行正式 500 题，未晋升或修改任何冻结内核。
