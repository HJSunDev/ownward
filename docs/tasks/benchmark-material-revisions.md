# 基准题目与资料修订（内部）

修订两类影响有效评测的问题：题目或预期答案缺乏合理依据；历史资料中的政治内容造成模型服务拒收。修订须保留原考核类别与难度，只纠正不合理之处或改写无关背景，维持原有能力要求，不以提高本产品得分为修改依据。

- **等难度是验收要求。** 对照修订前后的推理步骤、证据数量与分布、时间关系、信息量及干扰强度，不删除难点、不突出答案。原数据未提供逐题难度等级时，以这些结构建立对照；不能仅凭同题型、同长度宣称等价。
- **先固定修订，再评测。** 保存原版本、逐项差异、原因和独立复核依据，验证答案合理性与难度保留；不能只以本产品能答对或服务不再拒收作为通过条件。修订记录、标答与证据标签不得进入产品输入。
- **版本和结果可追溯。** 原始数据保留，修订版独立编号、单独报告；公开时提供变更说明与验证证据，不将修订版成绩冒称官方原版成绩。资料准备按[复用规则](../engineering/final-test-preparation-reuse.md)处理受影响来源及关联结果。
