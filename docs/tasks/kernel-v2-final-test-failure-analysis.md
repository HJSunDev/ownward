### 已修复、后续必须守住的机制

- **事实交付：** 当前语义线索覆盖不同的已陈述事实及限定条件，并参与可逐字核验的预览和片段选择；同时保留纯原文入口，避免摘要遗漏封死发现路径。旧截断线索仅在同来源原文中可唯一定位时恢复，不能从摘要补写事实。
- **取证接口：** 搜索提供可直接使用的原文证据和读取入口；紧凑引用兼容旧引用，来源、版本、区间及内容完整性校验不降级。只有摘要不能冒充已取得原文，已取得可信原文也不强制再调用一次读取。
- **共享执行：** 工具声明与实际条数上限已统一；来源编号匿名化，避免答案家族标签泄漏；有工具和无工具阶段均传递协作规则。改动须兼容原有关卡与最终测试，不来回切换实现满足不同入口。
