# 自主治理运行时实现对齐

> **状态**：已完成。
> **职责**：记录自主治理核心规则已经明确、但现有运行时尚未实现的功能变更；本文不修改核心需求，不替代 [`autonomous-development-governance`](../../.agents/skills/autonomous-development-governance/SKILL.md)，也不记录 Ownward 产品功能。

## 一、范围依据

本次变更以自主治理核心 Skill 当前相对既有版本的差异为范围：需求初心没有改变，新增表述只是把现有实现曾经画蛇添足的控制行为明确排除。实现必须向核心规则收敛，不能反向修改核心规则迁就现有代码。

当前运行时的真实行为和已确认偏差见 [`自主治理运行时实际行为核对`](../incidents/autonomous-governance-runtime-actual-behavior.md)。

## 二、必须完成的六项功能变更

- [x] **执行状态去审批化**：把获准工作包改为只描述当前目标、价值、进展、证据和下一验证点的执行快照，不再包含 Governor 批准或执行许可。
- [x] **治理关系顾问化**：Governor 只负责指出风险和更优路线，主 Agent 必须阅读并回应，但是否采纳和怎样执行始终由主 Agent 决定。
- [x] **彻底取消治理阻断**：Governor、Review 和治理 Hook 不得拦截工具、拒绝写入、冻结、暂停、接管主线或限制其他任务，且不得削弱项目原有安全与产品边界。
- [x] **启动与普通对话隔离**：稳定启动标识只把 Governor 接入当前主目标，治理开启后普通消息和同一对话中的其他工作仍由主 Agent 正常处理。
- [x] **单一治理支线与幂等触发**：同一主任务始终复用一个 Governor 和一份治理状态，同一触发重复投递不得生成重复复核或第二条治理支线。
- [x] **自然边界持续复核**：首次激活、恢复、上下文压缩和真实治理事件只在自然边界生成顾问反馈，保留有效状态与证据，Governor 失败或不可用也不能封锁主线。

## 三、完成边界

- 核心 Skill 保持未修改，运行时、Schema、Hook、Governor 配置、可复用模板、引用说明、状态迁移和测试全部与其一致。
- 现有治理状态中的有效进度、证据和检查点无损迁移，旧批准令牌、许可范围、冻结状态和阻断语义不再生效或残留。
- 普通消息、普通回复、Governor 启停、目标模式重复提示和其他任务均不创建无依据复核、不注入干扰指令，也不限制主 Agent 工作。
- 首次激活、恢复、压缩和真实事件能够各自产生一次正确复核，同一触发重放只复用已有状态，Governor 的反馈和主 Agent 回应可以跨上下文恢复。
- Governor 能真实发现低效、无价值或次优路径并给出更优方案，但运行时不能强迫主 Agent 服从。
- 六项变更全部完成后，已经以核心 Skill 为唯一判据完成一次对抗式复审；发现的真实偏差均已重新打开对应状态、完成修复并再次通过复审。
- 隔离自检、自动测试和真实冷启动流程均通过；Ownward 产品代码、架构、模块职责和既有功能没有变化。
- 本任务不运行 Ownward 产品正式验收，不执行 `git add`、`git commit`、历史改写或 `git push`。

## 四、完成核对

- 旧 Schema v1 已原子归档并迁移为顾问式 v2；运行身份、十一项完成条件、当前焦点、有效证据、检查点和真实主任务所有权均保留，旧批准与阻断语义不再活动。
- 项目只注册 `SessionStart`、`UserPromptSubmit`、`PreCompact` 和 `PostToolUse`；`SessionStart` 覆盖 `compact` 并通过模型可见的 `additionalContext` 交付压缩后复核，未注册工具门禁、通用 `Stop`、仅提供界面警告的 `PostCompact` 或子 Agent 生命周期 Hook。
- 全新 Codex 任务实测命中稳定标识、领取既有请求并通过原生父子通道取得只读 Governor JSON；反馈因随后代码变化发生快照漂移时被正确拒绝，本次 Review 标记为 `missed`，主线保持可用。
- 自动测试、完整构建、隔离 `doctor`、Schema/模板一致性和 Skill 校验均通过；真实主任务所有权已恢复，冷启动探测未留下平行状态或临时传输文件。
- 终态对抗式复审识别并修复了真实偏差：压缩后改由 `SessionStart(source=compact)` 向模型交付复核指令；同一待处理生命周期事件幂等、前次复核结束后的再次恢复可进入新代次；重复失败按排除易变元数据后的稳定类别关联；Hook 启动包装层在构建或启动失败时严格返回空结果；旧失败事实和迁移收尾可无损、可重入恢复；未到达检查点时 `next_action` 不再误写为完成态描述；可复用证据会绑定到后续快照，缺失或变更的证据会使旧完成结论失效并触发新复核，缺证检查点也会留下可恢复请求；Review 严格绑定创建时可见的证据与检查点，可用反馈不能被误降级为缺失，`finish` 只机械核验事实而不把 Governor 建成完成许可。对应回归测试、状态修复和最终无偏差复审均已通过。
