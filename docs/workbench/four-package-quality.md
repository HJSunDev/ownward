### 还原与使用

运行环境为Windows x64、Python 3.9或以上；内核和向量运行文件已附带。整目录即独立可用的备选，不需要覆盖工作区或回退Git。

```powershell
$archiveRoot = '归档实际位置/retained-check-exact'
python "$archiveRoot/replay.py" --check
```

校验会检查全部文件及38题原文、组织快照、流程、运行器、内核和有效协议，并确认从归档加载源码；不读取凭据、不调用模型。2026-09-12离线校验通过：38题资料与历史清单一致，历史成绩汇总核对一致。

需要重新验证时，指定已有轻量服务凭据文件和全新的输出目录，按6题、8题、24题顺序分别执行；每组结束后检查结果，14题全部通过后才进入24题：

```powershell
$credentialFile = '既有轻量服务凭据文件路径'
$resultRoot = '归档之外的新结果目录'
python "$archiveRoot/batch.py" --group 14a --output "$resultRoot/14a" --credential-file $credentialFile
python "$archiveRoot/batch.py" --group 14b --output "$resultRoot/14b" --credential-file $credentialFile
python "$archiveRoot/batch.py" --group 24 --output "$resultRoot/24" --credential-file $credentialFile
```

这些命令会产生新的模型调用和独立结果，不覆盖历史成绩；离线恢复校验不计新一次质量验收。原始现场仍保留于 `.tmp/four-package-quality/runs/retained-check-exact14-batch1/`、`retained-check-exact14-batch2/`、`retained-check-exact24/`，但恢复不再依赖它们。
