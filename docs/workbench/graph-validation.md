# 图能力实现验证

对应[图能力工作包](../research/graph-value-and-cost.md#工作包图能力设计实现与验收)。**2026-09-11：实现、代码验证与局部收益验证已完成；四个工作包合并后的整体质量尚未验收通过。运行已停止，成果与现场保留。**

固定14题的完整记录是10／14，固定24题是24／24；之后只有定向复验，不能拼成最新版全通过。开关图、原有资料及固定需求解析对照都沿用当前代码和规则，没有恢复四包前的完整已验收版本，因此不能排除前三个工作包的影响，也不能直接把剩余错误归为外部智能自身波动。

## 已交付的实现

既有语义协作接收证据单元、对象提及和有据关系；公共检索、导航、来源核对、快照替换、撤权、遗忘与恢复共同使用。没有新增内部模型、图数据库或固定在线推理链。

- 原文是权威，关系是可核对的派生解释；完整上下文、实际生成依赖和来源版本受到统一校验。
- 普通搜索不重复加权已直接入选的资料，不交付未入选关联；泛关联保留为弱候选及导航线索，明确关系按完整证据单元与需求的相关性参与扩展。
- 紧凑语义适配明确区分原文定位和单元引用，保留已接受成果，仅修被拒项。运行器逐来源发布并保存回执，避免一批来源的向量生成超过客户端等待后全部重做；公共批量接口仍存在，未声称消除了所有批量耗时。
- 无法回答题的裁判适配同时识别题号和 `unanswerable` 类型；补判复用既有答案，评分标准未改。

## 收益与成本

| 项目 | 结果及适用边界 |
| --- | --- |
| 已知方法的再次取用 | 最新语义整理的三组独立材料、每组三种等价表述，最多读取三份完整来源：导航全部取得必要依据；普通搜索两组各缺一份，另一组需读3份、导航只需2份。图的工具返回加原文约3.7—5.2KB，普通搜索约1.0—1.1KB；图返回更多字节，不能宣称整体token成本更低。导航输入不依赖需求措辞，此验证不代表智能体在所有场景都一定选择导航。 |
| 普通搜索的覆盖 | 原强加权在18个需求的8／16／32KiB预算下曾提高覆盖，但收益只出现在一组；4KiB反而下降。保守排序去掉干扰后，这项增益消失，不能沿用旧数据给最新版宣称普通搜索覆盖提升。完整关联导航仍保留。 |
| 最新存入成本 | 三组各五条短材料配对：原语义整理约20—34秒，增加关系整理正常完成约88—100秒；两组存储约21KB→27—28KB。一次服务已建立响应但长时间没有数据事件，约230秒后人工停止；只重试该项后完成，连同中断该组约330秒。中断费用未知，不能记为零。 |
| 长对话首次整理 | 第二批约50份历史对话、约0.5MB原文的首次关系整理约18—29分钟，包含纠错。不是一条经验的耗时，也不能因在后台就忽略其成本。 |
| 用户等待 | 原文先保存，普通读取不等待全库建图，取用没有恢复多阶段模型后处理；14题平均约137秒与原已接受方案约138秒接近。不得把毫秒级导航耗时冒充用户完整等待。 |

**取舍：接受有据关联作为长期信息复用能力，不把它当作所有普通搜索都会提分或提速的保证。** 在重复取用方法、依据和条件的产品场景中，已确认少遗漏或少读原文；五条短材料增加约一分钟的一次性整理、两组存储增加约6—7KB，不增加必需模型服务、用户维护步骤或在线后处理，按本工作包的持续使用场景成本可接受。若只查询一次，未必回本；大量历史首次整理仍明显较贵，不能隐去该代价，也不能要求用户等整理完成才使用原文。
