# 第一版验收基线依据

第一版的信息组织与检索采用三类互补证据：固定回归数据验证已知产品行为不再退化；候选冻结后生成的动态未见数据验证信息组织与检索的通用性；公开基准验证长期记忆能力的质量—时效前沿。三类证据分别解决历史回归、未知内容和公开对标问题，不能相互替代。

公开质量与时效以 LongMemEval-V2 Small 的官方评测器和 LAFS 前沿为主。它直接评估经验、流程、环境陷阱和前提适用性，并同时计入回答准确率与在线记忆查询时延。冻结时公开的 AgentRunbook-C V2 高质量点为 75.61% / 130.54 秒，Ownward 必须在相同读者、裁判、数据和预算下进入或超过该前沿；外部智能体主动检索固定使用官方条件中的 Codex CLI 0.117.0、`gpt-5.4-mini` 与 `xhigh` 推理强度。

动态验收不预先固定具体内容，只固定生成方法、覆盖分布、统一关系定义与方向、真值形成方式、裁判方法、资源预算、统计判定规则和通过标准；候选冻结后生成随机来源可追溯的具体内容，独立验证者排除关系类型或方向不能唯一判定的歧义样本，样本量由统计判定规则决定，不依据产品是否通过调整。

资源前沿以 `total-agent-memory v12.4.0` 官方源码标签为同机复现对象：它具备本地持久化、关系组织、384 维混合检索和 MCP 接入，并公开提供长期记忆质量结果。双方在十万条信息、十万组 384 维向量和近十万条关系下比较运行闭包、CPU、内存、存储、持久写入、基础可检索与语义检索内核；可替换模型运行时不计入这一等价的内核对标。十万组向量使用符合双方正式格式的固定数值构造，验证的是内核规模而不是模型吞吐，不执行十万次模型推理。

信息内核是 Ownward 自身的核心资产，必须排除可替换模型后独立证明其前沿性；完整产品资源验收只约束用户实际承担的交付成本，不能替代或稀释内核判断。最终交付形态必须另行计入发布包全部文件、模型、运行时、Ownward 启动的完整进程树及实际资产与派生数据，并测量安装体积、冷启动、空闲和工作状态资源。存在等价的完整本地产品时采用公开同类前沿；不存在单一可比对象时，分别采用信息内核公开前沿与已验证本地向量方案作为组件基线，并在查看最终候选结果前根据组件基线、重复测量误差和最低必要集成成本固定完整产品阈值。两条资源轨道独立判定、分别通过，不计算综合分，也不能相互抵消。

固定回归数据是为本次验收编写的合成信息，不包含用户的真实个人信息，也不向体系提供类型或关系答案。它已经参与实现诊断与调优，其中既有关系金标采用一组精确标签，只保留为历史诊断信息，不以唯一匹配判定开放语义质量；固定集继续硬性验证资产、语义协作完成、检索和已知行为不退化。关系准确性与覆盖率的正式证明由采用统一关系定义并经独立歧义验证的动态未见数据承担。固定集和动态集均分别记录外部语义协作耗时；Ownward 自身操作时延按冻结边界验收，外部智能能力没有公开可比依据时不采用任意绝对门槛，但必须受异常停止和成本核算约束。
