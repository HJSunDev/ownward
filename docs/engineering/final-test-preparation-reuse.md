# 最终测试资料准备与复用

将提问前的资料准备分层保存，按真实依赖判断复用与重建范围。信息使用层及查询侧迭代通常不改变存入结果，因此准备复用价值高；存入机制变化时只重做受影响部分及其依赖，不因整个程序版本变化就全部重新准备。

| 准备层 | 保存什么 | 哪些变化使其失效、需要重新准备 |
| --- | --- | --- |
| 原始资料 | 每题完整历史对话、日期、顺序、来源及隔离边界；保留官方原始文件和导入后的内容。 | 对话内容、日期、顺序、资料边界或导入处理方式改变时，重新准备受影响资料；官方原始文件未变则继续保留。 |
| 语义组织结果 | 外部智能生成的检索线索、证据组织与有据关系，以及生成时使用的材料和设置。 | 存入阶段的提示词、模型及档位、输出合同、材料分组、参考上下文、组织或校验规则改变时，重新组织受影响部分。原始资料变化引起的关联影响也须纳入；向量或候选检索变化若改变组织输入，同样使本层失效。 |
| 可检索的数据状态 | 原文与组织结果对应的存储状态、向量及索引，保存为答题前的独立快照。 | 上游资料或组织结果、向量模型、索引生成方式、存储格式或写入规则改变时，重建受影响部分；兼容迁移须验证等价性。仅修改查询排序、读取或展示，且不改变存入过程时，无须重新组织资料。 |

**长期共用存放。** 准备材料统一存放于配置的评测数据根目录下的持久化 `prepared/` 目录，按数据集版本、题目ID、准备层及其依赖标识组织，与单次运行的回答、判分和日志分开。后续新增题目的准备补入同一共用目录；各轮测试引用符合依赖条件的材料，使用独立的可写副本，不改动共用快照。目录与材料不绑定某次任务、抽题批次或题间执行顺序。

**顺序与覆盖独立。** 分层抽样、顺序全跑或补跑均按稳定题目ID取用同一份准备，抽题名单及执行次序不改变材料身份；每题内部的历史对话顺序和资料边界仍须保持。答题失败不使准备自动失效，是否重做只取决于下述依赖变化。

**判断以依赖为准。** 仅修改需求分析、取证作答提示词、信息使用流程或裁判，不使上游资料准备自动失效；修改公用提示词或实现时，须核对其是否同时参与存入。每层保存输入、相关实现、提示词、模型设置和产物的校验信息；旧结果保留，新准备另存。

准备与评测续跑共用语义实现标识，覆盖实际调用的提示拼装、分组预算、输入编码及校验方法；原文导入单独记录依赖，不能仅检查入口函数是否变化。

准备入口检测到依赖标识变化时先停止，列出差异，不自动重新调用AI；二进制或接入文件变化须核对实际影响，不能仅凭文件变化判定语义材料失效。确认需要重建后使用`--rebuild-changed`另建状态，仍有效的原始资料及旧状态保持不变。

仅修复定位编码或失败恢复时，先核验已接受结果的原文位置、组织内容及来源依赖是否仍然有效；可证明兼容的材料保留，仅重做受影响部分。兼容核验依据与原始生成记录同时保留，不能只改依赖标识冒充新版生成；新的自动纠错能力须独立验证，旧快照不能代替该验证。

**公平性边界。** 准备过程仅使用规定的历史资料，不提供测试问题、标答、答案来源标签或判分反馈，不依据答题成绩挑选组织结果；保持原有资料顺序、组织上下文与题间隔离。每轮从同一答题前状态独立取证作答，不将上一轮运行状态带入。

首次准备的耗时、调用费用及存储成本单独记录，复用不代表这些成本消失。独立复跑重新生成回答与判分；固定准备结果下的复跑验证取用质量，不替代存入阶段独立重建的质量验证。

## 必要操作与耗时参考

准备前先核对上述依赖，优先复用合格材料；只补缺失或失效部分，保留已完成单元，独立工作并行执行。首次组织先以小批实测质量与成本，再扩大准备；不通过省略正式能力或降低校验要求换取提速。

批量执行最多6题并发、共享8个AI请求位，沿用既有CPU配额。已确认属于单题的语义生成或校验失败单独记录，其他题继续补位，不扩大原有重试预算；公共或无法确定范围的异常立即停止派发并保留在途结果，不以独立材料错误的数量判定公共故障。失败题保持未完成，接续时复用已接受资料。

| 操作 | 何时执行 | 每题耗时参考 |
| --- | --- | --- |
| 校验完整原文并复制到所需位置 | 校验待用材料；已有合格副本无需重复复制 | 约0.009秒／题 |
| 将原文写入内核 | 缺少可复用的数据状态时 | 约1.52秒／题 |
| 外部智能生成检索线索与必要的有据关系，内核校验发布并维护索引 | 缺少有效组织结果时生成；已有有效结果只执行必要的恢复或重建 | **约5分30秒／题（估算，不含其他题排队）** |
| 校验答题前快照，复制数据为独立运行副本 | 使用已有完整快照时 | 约0.15秒／题 |
