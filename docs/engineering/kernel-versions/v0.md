## 实现

| 方向 | V0 实现 |
| --- | --- |
| 信息表示与组织结构 | 长期资产与派生状态分离；稳定身份承载来源与明确语义，外部语义结果形成带版本、依据、置信度和场景的关系图。 |
| 检索架构与算法 | 直接读取、词法与 512 维向量独立召回，等权倒数排名融合；高分种子进行一层关系扩展，再按场景校验、排序和截断。 |
| 语义能力与表示模型 | 外部智能体通过 `semantic_work` / `semantic_submit_batch` 提交语义候选，内核校验身份、版本、证据与冲突；EmbeddingGemma 300M Q8 提供本地向量。 |
| 数据结构与存储架构 | 无损资产日志保存权威信息；关系、向量与索引进入可重建派生世代，当前世代完整校验后原子切换，运行索引和缓存可销毁。 |
| 执行架构与状态维护 | Go 内核管理批量沉淀、语义工作、派生重建和恢复；向量运行时由 Ownward 管理，失败时保留资产及上一有效世代。 |

| --- | --- |
| 核心不变量 | 资产保存、更新、备份恢复、派生重建、稳定身份、派生可销毁、模型可替换：`7/7` 通过。 |
| 内核质量（固定集） | 身份、增量一致性、合并拆分、关系精确率/召回率、图召回率、融合召回率和上下文精确率均为 `100%`；词法召回率 `97.30%`，向量召回率 `98.37%`，融合 NDCG `99.24%`。 |

## 判断

**长板**：资产与派生状态边界可靠，恢复与演进不变量完整；固定内部场景质量高、内核查询快；单会话事实记忆稳定。

**短板**：多会话、时间推理、偏好与知识更新明显不足；258 个错误中，116 个首次缺口是搜索未返回目标证据，133 个是目标证据未被读取，另有 9 个在读取证据后仍答错。内部测试已接近饱和却未覆盖这些复杂失败；正式运行还消耗 `96.91M` 语义输入 Token 和 `8.65 GB` Ownward 数据，组织成本过高。

上述缺口是后续大版本的基线，不作自动根因归因。
