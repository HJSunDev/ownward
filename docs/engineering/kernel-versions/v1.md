## 实现

| 方向 | V1 实现 |
| --- | --- |
| 信息表示与组织结构 | 长资产按需生成带来源身份的细粒度证据，避免整段会话直接占满上下文。 |
| 检索架构与算法 | 按来源排名和证据深度进行有界公平装载；短资产完整读取，长资产检索并读取源绑定区间。 |
| 语义能力与表示模型 | 为长资产建立语义表示，使其能够进入向量召回；继续校验语义工作身份、版本和原序提交。 |
| 数据结构与存储架构 | 派生状态升级为紧凑格式，权威日志保留当前资产快照并原子压实，重复维护只保留每资产一个当前派生记录。 |
| 执行架构与状态维护 | 批量创建和候选世代构建按事务边界合并耐久写入，校验完成后统一持久化并原子发布。 |

| 范围 | 结果 |
| --- | --- |
| 核心不变量 | 资产保存、更新、备份恢复、派生重建、稳定身份、派生可销毁、模型可替换：`7/7` 通过。 |
| 内核质量（固定集） | 身份、增量一致性、合并拆分、关系精确率/召回率、图召回率、融合召回率和上下文精确率均为 `100%`；词法召回率 `97.30%`，向量召回率 `98.37%`，融合 NDCG `99.24%`。 |
| 内核效率（固定集） | 组织 P95 `0.54 ms`，索引构建 `0.81 ms`，融合查询 P95 `0.54 ms`；派生数据 `14,380 B`，索引 `529,080 B`。 |
| 产品专项 | 24 个场景全部通过，跨时间、多跳、场景适用和信息更新的召回率、精确率、NDCG 均为 `100%`；查询最长 `283.05 ms`，峰值内存 `256.00 MiB`，场景端到端最长 `15 分 28.75 秒`。 |

## 历史 LongMemEval-S 被动评测

以下运行采用官方清洗 500 题、`gpt-5.6-luna` 语义与 Reader、`gpt-5.6-terra` 裁判，但宿主固定预取并决定读取顺序。数据与计分记录保留，结果只描述旧被动评测模式，不证明 V1 产品能力、相对 V0 的内核收益、退化或晋升资格。

旧被动口径下，V1 相对 V0 有 101 道错题转为正确、58 道正确题转错，净增 43 题；这些差异不得归因于产品定义的主动检索内核。

## 判断

**已独立证明的收益**：长资产语义表示、细粒度证据、批量耐久写入和存储收敛成立；创建阶段累计耗时由 `2,750.0 秒` 降至 `705.3 秒`，Ownward 数据由 `8.65 GB` 降至 `399,536,519 B`。

**待重证**：旧被动口径观察到读取后答错、既有正确题转错和检索时延上升；因观察器替代了外部智能体决策，这些现象不能裁决 V1 的主动检索质量或根因。

V1 不晋升。主动检索同尺比较中，V1 为 `20/20`，累计墙钟 `277.516 s`、检索均值 `106.25 ms`、P95 `203 ms`、数据量 `1,220,376 B`；该结果不构成正式分数。V1 的独立收益继续有效，旧结果只作历史被动诊断；完整证据见[纠偏结果](../../../benchmarks/acceptance/suite/iteration/evaluation-correction/product-faithful-comparison.json)。
