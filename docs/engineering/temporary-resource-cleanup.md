# 任务临时资源的收尾

任何任务只要产生临时资料或占用临时运行资源，创建者就负责收尾，直到另一方明确接手。一次性任务用完即收；失败、取消或交接时，释放已无人使用的部分。交付成果不纳入临时清理，仍待答复的信件和仍在复核的材料继续保留。

一次性安装、解包和测量使用本次验证独占的工作根。先结束本轮自有进程、释放句柄，再按[删除资源技能](../../.agents/skills/delete-resources/SKILL.md)回收整个工作根。共享工具、缓存、精确交付制品和不可重建的失败输入放在工作根外；产品数据及其保留义务由产品合同管理。

相同的只读输入可以复用，干净安装、可写状态和冷测所需的隔离仍须保留。一次性环境在最后一个使用者结束时释放；A/B基线、未完成独审或故障复现等例外，在既有交付记录中注明消费者、保留原因和释放时点。只有哈希不能重建丢失的资料。

耗时回收避开性能采样，同一时刻只运行一个回收作业。换轮先接续回收或复用空闲容量；中断后核对原作业，仍在用的资源继续保护，不按目录年龄强删。不为普通清理增加逐文件台账、定时扫盘或审批。
