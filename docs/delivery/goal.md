# 目标

构建一套属于用户而非任何智能个体、与通用智能体平级的个人信息基础设施，使用户本人以及现在和未来任何形态的智能个体能够通过同一核心检索、读取、创建和更新用户长期持有的广义个人信息，并使现有主流智能体能够方便接入。体系以最低必要成本完成信息沉淀，自主建立并持续维护多维语义关系，向智能个体提供使用、维护和主动补充信息所需的规则，将真实使用中产生的经验和教训持续回流，使后续工作直接受益。个人信息资产必须独立于任何智能个体、设备、第三方服务和某一代内核而长期存续、可完整恢复，检索时效、检索质量和信息组织质量始终处于同类能力前沿。

## 项目规范

项目整体须达到顶级开源项目标准，从目录结构、代码、文档到工程实践均保持清晰、严谨、完整且经得起长期演进，使其专业性与可信度能够被直接理解和验证。

## 性能目标与语言选择

系统必须在不牺牲功能完整性、信息质量和资产耐久性的前提下同时做到轻量与快速：程序体积及 CPU、内存和存储资源占用处于同类系统最低水平，信息写入、持久化、组织、索引和检索的端到端效率处于同类系统前沿。编程语言不作预设，以实现上述产品目标为依据，自主选择最合适的语言或语言组合。
