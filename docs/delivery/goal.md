# 目标

构建一套属于用户而非任何智能个体、与通用智能体平级的个人信息基础设施，使现在和未来任何形态的智能个体能够通过同一核心检索、读取、创建和更新用户长期持有的广义个人信息，并使现有主流智能体能够方便接入。体系只面向外部智能体提供核心能力，不直接面向用户，也不内置智能体；用户通过外部智能体使用体系，面向用户的显示、编辑与交互由外部智能体产品承担，本产品不关注。体系以最低必要成本完成信息沉淀，自主建立并持续维护多维语义关系，向智能个体提供使用、维护和主动补充信息所需的规则，将真实使用中产生的经验和教训持续回流，使后续工作直接受益。个人信息资产必须独立于任何智能个体、设备、第三方服务和某一代内核而长期存续、可完整恢复，检索时效、检索质量和信息组织质量始终处于同类能力前沿。

信息范围包括个人经历、心理活动、社会经验、知识、技能、工作信息、实践方法，以及智能个体形成的错误教训、解决经验和可复用路径。体系只承载属于用户、可长期复用的信息；仅属于某个智能体的短期记忆不在范围内。体系自主维护多重归属、层级、交叉、组合及必要的场景关联，不要求使用方设计信息结构。

内核提供基于结构化关联的可组合、可迭代检索能力；智能个体依据累计证据主动推进检索，简单检索可以一次完成，复杂检索能够根据中间结果持续调整方向，直至获得满足当前目的的完整信息。

## 项目规范

项目整体须达到顶级开源项目标准，从目录结构、代码、文档到工程实践均保持清晰、严谨、完整且经得起长期演进，使其专业性与可信度能够被直接理解和验证。

## 性能目标与语言选择

系统必须在不牺牲功能完整性、信息质量和资产耐久性的前提下同时做到轻量与快速：程序体积及 CPU、内存和存储资源占用处于同类系统最低水平，信息写入、持久化、组织、索引和检索的端到端效率处于同类系统前沿。编程语言不作预设，以实现上述产品目标为依据，自主选择最合适的语言或语言组合。
