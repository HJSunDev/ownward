# 关联信息的可靠取用

**让不同时间存入的信息共同发挥作用：智能体能找到相关依据，分清对象、经历和适用条件，减少重复查找与错误关联。** 用户仍通过正在使用的智能体表达目标、保存经历和更正信息，无需学习或维护图结构。

本文细化[信息组织与主动检索需求](requirements.md)，规定产品行为与验收要求；技术方案见[关系组织架构](../modules/semantics/graph-organization.md)，实施状态见[图能力工作包](../research/graph-value-and-cost.md#工作包图能力设计实现与验收)。

## 用户获得什么

| 使用情境 | 应获得的体验与增益 |
| --- | --- |
| 重新使用过去的方法或经验 | 找到方法时，也能取得相关依据、适用条件与已知反例；即使原来能够完成任务，也可以少翻资料、少遗漏条件。 |
| 跨记录找人、事项或经历 | 不必记住所有名称与原话；能够沿真实关联找到其他记录，并分清同名对象、不同事件及其参与角色。共同出现不被当作事实关系。 |
| 换智能体继续工作 | 在相同授权下复用体系已有的关联，不从上一智能体的私有上下文重建；仍由接入智能体理解当前目的和判断如何使用。 |
| 收回某个智能体的访问 | 该智能体按新的权限停止访问或维护，其他获授权智能体仍可使用共有信息；收回访问不等于遗忘内容。 |
| 更正、变化与遗忘 | 保留真实历史和适用条件，停止使用失去依据的关联；遗忘覆盖受控派生内容。沿用[信息变化](information-change.md)和[用户掌控](information-control.md)的行为，不要求逐条修复关联。 |

例如，记录分别保存了“项目采用过的方法”“方法的适用条件”和“后来出现的反例”。用户再次处理类似工作时，智能体应能一并找到这些依据；另一项目出现同名方法，并不意味着两者条件相同。

## 使用方式与范围

- **保存照常进行。** 内容先可靠保存并可直接查找，关联整理不能成为保存成功的前提；整理不完整时不伪装成信息丢失或已经全部整理。只在影响当前任务时说明局限，不向用户连续报告内部工作状态。
- **取用自然受益。** 普通搜索与读取能获得有用的关联入口和原文依据，复杂需求可以继续探索；不增加“开启图”“选择深度”或等待全库整理的必经步骤。体系重新整理关联时，用户无需重新保存或手工修复连接，原文和未受影响的信息继续可用。
- **冲突如实保留。** 关联帮助找到不同说法，不裁定哪方为真；保留来源、时间及条件，证据不足时支持有依据的限定或澄清。用户的合理诉求不能因资料不完美被放弃。
- **取舍留给智能体，控制留给用户。** 智能体核对原文并完成需求；用户只处理自己的目标、重要边界和必要澄清，不承担分类、实体消歧或修图任务。

交付范围是原文定位、对象与事项关联、依据与条件的导航，以及这些组织结果的更新和失效。完整世界本体、全库主题报告、图可视化、独立图数据库运维和自动事实裁决均不属于该范围。

## 验收要求

以同一批原始信息、需求、外部模型和档位、读取预算、硬件与并发比较；先固定必要证据及合理关系，再运行候选。覆盖普通查找、间接关联、同名与多事件、条件冲突、新增更正、遗忘及资料增长，不用一道题的对错判断价值。

| 方面 | 通过条件 |
| --- | --- |
| 真实增益 | 在相同阅读预算下增加必要依据或完整关联链，或以更少搜索、阅读、模型工作取得同等质量；收益须在独立材料及需求改写中重现，不能仅体现为多返回内容、关系数量或更高自报置信度。 |
| 忠实性 | 抽查对象、方向、事件边界、条件与原文一致；错误连接、过时信息和无关材料不抵消覆盖收益。明确更正不被相关度排序挤掉，来源失效和遗忘不得泄露或复活旧内容。 |
| 原有能力 | 普通查找及已验证的信息使用能力不退化；按照受影响范围复用固定验证材料，不能以图的增益抵偿已有质量下降。 |
| 完整等待 | 分开记录保存返回、关联可用和需求到可用结果的等待，并计入尾部与重试。普通查找不因等待关系整理而阻塞；关联任务的增益也须满足已认可的使用时效，固定14题沿用[时效边界](../tasks/single-task-latency.md#当前任务保持质量消除取用信息的额外等待)，不恢复多分钟的固定串行后处理。 |
| 持续成本 | 纳入首次整理、重复使用、更新纠错、存储、内存及恢复；允许为可靠增益承担合理增量，但不新增必需模型服务或用户运维步骤，不因资料增长形成全量反复推理或无界派生膨胀。后台成本与首次使用成本不能隐藏。 |

质量、易用性和可接受等待须同时成立。最终证据应说明“取得什么可靠增益、为此增加或节省多少完整成本”，并满足[第一版交付约束](../delivery/first-version-delivery-definition.md)；只完成建图或让原本能答对的题再次答对，不构成验收通过。
