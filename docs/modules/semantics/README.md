# 语义理解架构

本文规定持续进步的智能能力如何参与 Ownward 的信息理解，以及语义能力、信息内核和派生组织状态之间必须长期成立的边界。

## 产品判断

**Ownward 不把某个模型或智能体当作内核；它通过稳定语义边界使用可替换的外部智能能力，并始终掌握信息资产和组织权威。**

语义能力负责理解开放内容，Ownward 负责把理解转化为可靠、可演进的组织与检索能力。语义能力进步时体系可以随之变好；智能体、模型和协议变化时，用户资产与核心结构不需要迁移。

    K["Ownward 内核<br/>资产与组织权威"]

“外部智能体”和“外部语义能力”是两个逻辑角色，不要求由两个独立产品承担。长期架构只要求语义能力可替换，不绑定某个智能体、会话、模型、服务或协议；第一版由已经接入 Ownward 的同一个外部智能体兼任两个角色，不内置第二个智能体，也不要求额外模型服务或密钥。

## 职责边界

| 参与方 | 职责 |
| --- | --- |
| 外部智能体 | 代表当前任务使用信息，选择主动检索方向，评估累计证据并组织结果。 |
| 外部语义能力 | 依据内核提供的资产与上下文，提出带来源、依据和不确定性的关系、归属、场景及其他语义候选。 |
| Ownward 内核 | 先保存资产，形成有界语义工作，验证身份、版本、来源、证据完整性和结构不变量，管理冲突、不确定性、派生世代与检索使用，并对组织和检索质量负责。 |
| 本地向量能力 | 生成语义表示并支持候选召回，不判断内容真伪、关系或场景，不形成组织权威。 |
| 接入适配 | 映射外部能力与核心契约，不保存私有真相，也不绕过内核写入资产或组织状态。 |

语义能力不为用户维护目录、分类体系或全局关系结构，也不能直接改写长期资产和关系图。内核不把候选判断当作事实，不假装独立验证开放语义的真伪，也不能用领域词表、句式规则、固定分类或验收样本替代理解；它通过来源、证据、不确定性、冲突和结构约束决定候选如何进入可修正的组织状态。

## 语义闭环

1. 信息先以稳定身份进入长期资产；任何理解失败都不得造成资产丢失。
2. 内核依据资产版本、当前组织状态和待解决问题形成最小充分的语义工作。
3. 外部语义能力返回带有来源、依据和不确定性的候选判断；无法可靠判断时明确保留未知。
4. 内核验证候选与当前资产和结构是否相容，记录来源与能力世代，管理冲突，并将可接受结果纳入新的派生组织世代。
5. 新信息、明确纠正或语义能力升级可以触发重新评估；旧理解可失效、重算和替换，但不得改写其所依据的长期资产。

语义理解与主动检索相互独立：前者帮助内核形成组织状态，后者代表当前使用目的选择检索路径。第一版即使由同一智能体兼任，也必须经统一契约中彼此隔离的能力与权限边界完成，不能把临时任务判断混入长期组织状态。

## 故障与演进

外部语义能力暂时不可用时，信息仍然进入资产并保留明确的待理解状态；稳定身份读取以及不依赖该判断的词法、向量和直接检索继续工作。内核不得以低可信启发式结果冒充语义完成。

每项派生语义都必须能够追溯到资产版本、语义能力来源、依据和生成世代，并能失效、重算和原子切换。恢复长期资产不依赖任何语义能力；恢复完整组织状态时，由当前可用的语义能力通过同一契约重新完成必要理解。

---

## 第一版架构落点

第一版完成稳定的语义工作获取与结果提交能力，由已经接入 Ownward 的主流外部智能体兼任语义能力。内核接收带来源、依据和不确定性的候选结果，执行身份、版本、证据和结构校验，管理冲突并持久化为可重建派生状态；它不对开放内容真伪作无依据的二次判断。

协作中断、结果过期或无法判断时，资产安全且状态明确。批量沉淀与重建形成有界工作单元，复用不依赖查询答案且来源仍有效的语义结果，不把容量规模机械放大为逐条重复智能推理。正式验收只接受这条产品路径，不得注入测试语义实现、旁路模型服务或内容特判。
