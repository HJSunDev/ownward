# 固定 Ownward 专项数据集适配

适配器按场景建立相互隔离的 Ownward 分区，只通过发布二进制的 MCP 公开能力创建、更新、组织和检索固定信息。语义理解与主动查询分别由隔离的外部 Codex 会话完成；会话看不到真值，不能使用非 Ownward 工具。每个场景形成绑定候选、环境、输入、工具和资源证据的独立检查点，中断后只重做未完成场景。

统一入口负责生成无真值任务、调用本适配器并以隐藏真值评分。适配器必须同时取得已绑定同一候选的资源报告；资源证据只执行一次并在专项场景间复用。每个场景分别记录 Ownward 内核查询、外部语义协作、智能体查询和端到端耗时，完整呈现成本但不把外部智能体耗时误作内核门槛。
