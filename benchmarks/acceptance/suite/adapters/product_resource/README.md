# 专项层完整交付资源适配

本适配由 Acceptance Suite 专项层调用，资源结果只进入专项层质量、时延、资源分轨证据，不构成独立完成判定。验收对象必须是由当前候选二进制、锁定的 EmbeddingGemma 能力包、Ownward 许可证和使用说明组成的完整发布目录。

测试只对少量代表性文本执行真实模型推理；十万条容量使用 `ownward-performance` 直接构造的 512 维生产格式派生状态，不执行十万次模型推理。进程资源统计覆盖 Ownward 及其启动的完整子进程树。

该适配器只能由统一入口随 `qualification` 或 `full` 调用；独立执行结果不构成验收证据。
