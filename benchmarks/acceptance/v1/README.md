# 第一版固定验收基线

本目录在产品实现调优前冻结。Ownward 必须在同一候选版本、固定输入和固定外部智能体条件下通过全部轨道；不得修改数据、答案、阈值或挑选子集。基线本身若被独立证据证明错误，应新建后续版本并保留本目录。

`baseline.json` 固定环境、规模、指标和阈值；`fixtures/information.jsonl` 是不含组织答案的输入；`fixtures/relations.jsonl` 与 `fixtures/queries.jsonl` 只供验收器评分。公开前沿轨道使用上游原始数据与官方评测器，不把数据复制进仓库。

执行入口将在实现稳定前补齐；完整验收必须保留逐项原始结果、进程资源采样、构建产物摘要和外部基线版本。
