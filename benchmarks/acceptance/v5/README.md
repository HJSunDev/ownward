# 第一版固定回归基线 v5

v4 的三条关系查询在关闭关系扩展时，前十名已经包含全部预期信息，因此召回率增益的数学上限为 `0`，与 `0.05` 的通过阈值矛盾。v5 将该无效指标改为关系图带来的正确关系证据覆盖增益，阈值仍为 `0.05`；输入、金标、查询和其余阈值全部不变。公开 LongMemEval-V2 继续验证完整产品的主动检索质量与时效。

本基线已经参与实现调优，只承担历史回归验证，不作为动态未见验收或第一版完成的独立证据。既有关系金标采用一组精确标签，关系准确率、覆盖率和外部语义协作耗时只作为诊断结果；固定集硬性验证资产保真、语义协作完成、检索结果与历史行为不退化。开放语义关系质量由采用统一关系定义并经独立歧义验证的动态未见验收证明。
