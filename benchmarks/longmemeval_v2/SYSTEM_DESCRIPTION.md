# Ownward

Ownward is a local personal-information foundation. It preserves authoritative information assets and maintains disposable lexical, vector, contextual, and graph-derived state. For LongMemEval-V2, one shared Ownward state is built per domain; isolated external-agent sessions actively search, read, and navigate that state through Ownward's public MCP interface before the official reader and judge evaluate the answer. The benchmark adapter does not expose benchmark truth to Ownward or the retrieval agent.
